# TikTok Stickers Grid Generator

Site web statique pour la découpe et la conversion de vidéos en 6 carrés de 354x354 px avec coins arrondis de 30 px pour stickers TikTok.

## Fonctionnalités

- Découpe en 6 carrés de 354x354 px
- Coins arrondis de 30 px sur chaque carré
- Espacement de 24 px par défaut
- Grilles 3x2 et 2x3
- Export MP4 et GIF
- Structure ZIP avec dossiers "full overlay" et "Case par Case"

## Déploiement GitHub Pages

1. Créer un dépôt sur GitHub
2. Pousser les fichiers du dossier :
```bash
git init
git add .
git commit -m "TikTok Stickers Studio"
git branch -M main
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```
3. Activer GitHub Pages dans Settings > Pages (branche main, dossier root).
